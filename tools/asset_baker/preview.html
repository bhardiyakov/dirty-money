NPCs 2,5D — prévia do gerador

Fichas e animações em tools/asset_baker/generator/ (porte do gerador Python do pacote de NPCs + animações novas do jogo), 16 direções, renderizadas aqui na hora. Os atlas do jogo (assets/baked/: WebP + JSON, com as camadas de dano) saem do build: npm run bake (ou node tools/asset_baker/bake.cjs [tipos]). As cores das variantes não precisam de atlas novo.
