Carros 3D — gerador do arquivo do jogo

Gera os carros com o gerador procedural (gerador/, o mesmo do pacote "veiculos3d") num nível de detalhe leve para o jogo e grava assets/cars/carros3d.js. A vista abaixo usa o MESMO código do jogo (src/art/CarArt3D.js): pintura, amassado, luzes, rodas e balanço.
Abra pelo servidor de desenvolvimento (serve.ps1 → http://localhost:8123/tools/carros3d/).
